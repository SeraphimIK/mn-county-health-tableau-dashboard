# Minnesota County Health Dashboard (Tableau)

A Tableau-ready dataset and complete dashboard design for visualizing health outcome measures across Minnesota's 87 counties.

## Why I built it

I wanted to practice preparing a real dataset for a BI tool, including percentile columns for easy color coding, and to plan out a specific dashboard instead of just describing one, so it could actually be built.

## What's in it

- `mn_county_health_tableau_ready.csv`: 87 MN counties, the same 4 health measures used in the SQL and Python projects in this portfolio, plus a percentile rank for each measure
- `DASHBOARD_DESIGN.md`: the full dashboard specification, worksheets, a suggested calculated field for a composite risk score, and dashboard layout

## Data source

County Health Rankings & Roadmaps, 2025/2026 measure release. See the companion SQL project's README for full source details.

## Honest note

This is data preparation plus a complete design spec, not a finished Tableau workbook, since Tableau software wasn't available in the environment this was built in. See `DASHBOARD_DESIGN.md` for exactly what to build and how.
